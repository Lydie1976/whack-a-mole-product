# Product Spec — 打地鼠：花園大作戰

本專案是產品級打地鼠瀏覽器遊戲，不是 MVP。核心體驗參考主流打地鼠機制：限時反應、隨機出現、打中得分、漏打懲罰、速度提升、最高分、排行榜、特殊目標與負面目標。

## 產品定位

- 中文名稱：打地鼠：花園大作戰
- 英文副標：Whack-a-Mole: Garden Rush
- 風格：溫暖可愛、花園主題、親子友善。
- 目標玩家：兒童、親子、休閒玩家、短時間反應力玩家。
- 單局時間：60 秒。
- 操作：滑鼠點擊或手機觸控。

## 核心功能

- 主選單、玩法教學、排行榜。
- 60 秒限時遊戲。
- 3x4 共 12 個洞。
- 起始 3 顆生命。
- 一般地鼠、黃金地鼠、炸彈鼴鼠、冰凍地鼠、愛心補給、園丁 Boss。
- 分數、最高分、時間、生命、等級、Combo、暫停、重玩。
- 打擊分數動畫與 UI transition。
- Web Audio API 音效。
- localStorage 保存最高分、排行榜、音效偏好。
- 手機、平板、桌機響應式。

## 玩法規則

- 一般地鼠：打中 +10；漏打 -1 生命。
- 黃金地鼠：打中 +30；漏打 -1 生命。
- 炸彈鼴鼠：打中 -20 並 -1 生命；不打不扣分。
- 冰凍地鼠：打中 +15 並 +2 秒；漏打 -1 生命。
- 愛心補給：打中回復 1 生命，最多 3 顆；漏打不扣分。
- 園丁 Boss：分數與等級達標後出現一次，需要連打 3 下，成功 +80；漏打 -1 生命。
- Combo：連續打對 5 次後，每次額外 +5 分；打錯或漏打歸零。
- 難度：依分數提升，最高 9 級；低等級同時最多 1 隻，高等級最多 3 隻。
- 結束條件：時間歸零或生命歸零。
- 結算：顯示本局分數、最高分、命中率、最大 Combo、評語、排行榜與分享文案。
